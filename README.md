### 🌶️ Zest — o tempero do seu terminal

Zsh produtivo para **qualquer distro Linux**, sem precisar de root:

![release](https://img.shields.io/badge/release-v0.1.6-8A2BE2) ![plataforma](https://img.shields.io/badge/plataforma-qualquer_Linux-success) ![root](https://img.shields.io/badge/root-n%C3%A3o_necess%C3%A1rio-brightgreen) ![docs](https://img.shields.io/badge/docs-Portugu%C3%AAs-blue)

```bash
wget -qO- https://github.com/reginaldosevero/zest/archive/refs/heads/master.tar.gz | tar xz
cd zest-master && bash install.sh --with-omz
```

- 📊 `sysinfo`/`topmem` com barras coloridas que qualquer pessoa entende
- 🔄 `updateall` — 12 gerenciadores de pacote em um comando
- 📝 notas, clima, notícias e cotações direto no terminal, em português
- 🛡️ instalador aditivo, idempotente e reversível
